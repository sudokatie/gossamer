# Gossamer Features

A quick overview of what Gossamer can do.

## Markdown Extensions

- **GFM Tables** -- GitHub-flavored markdown tables
- **Footnotes** -- Reference-style footnotes[^note]
- **Smart Typography** -- Curly quotes, em-dashes, ellipses...

## Layouts

Create `_layout.html` in any directory to customize the template. Use placeholders:

- `{{content}}` -- The rendered HTML
- `{{title}}` -- From front matter
- `{{date}}` -- Post date if available

## Draft Support

Add `draft: true` to front matter to exclude a page from builds.

## Dev Server

`gossamer serve` starts a local server with:

- Live rebuild on file changes
- Request logging
- Port 3000 by default
